# GitHub Projects 管理

- 项目看板的地址以目标项目自己的 `AGENTS.md` / `CLAUDE.md` / README 为准；没有看板就只在 issue 中记录，不自行新建看板。
- 创建或更新 issue、创建 PR 后，检查其是否已加入 Project；若项目已启用仓库 issue / PR 自动入板，未入板时手动补充，避免重复条目。
- 状态维护：`Todo` 为待处理，`In Progress` 为正在实施或评审，`Done` 为已完成。开始工作和交付时同步项目状态，在关联 issue 中记录进展、验证与结论。
- PR 关联对应 issue；合并代表代码交付，关闭但未合并的 PR 必须保留关闭原因，不能据此声称功能已完成。
- 历史设计和实施计划通过 Project README 索引查阅；不要仅凭旧文档建立重复需求或推断未完成状态。
- 若 Projects 权限或工具不可用，继续在 issue 中记录，并明确说明未同步的项目状态；不得声称已入板或已更新状态。
