# wukong-code-projects

Claude Code skill：悟空的项目协作规则（SDD、TDD、根因调试、完成前验证、GitHub issue / Project 管理）。

## 安装

```bash
git clone https://github.com/wukongnotnull/wukong-code-projects ~/.claude/skills/wukong-code-projects
```

之后在任何项目里，Claude 遇到写 spec、写代码、修 Bug、提交 / 开 PR、建 issue 等场景会自动加载。

## 结构

- `SKILL.md`：始终遵守的规则与细则索引
- `references/`：按需读取的细则

`references/coding.md` 改编自 [Karpathy Guidelines](https://github.com/multica-ai/andrej-karpathy-skills)（MIT）。
